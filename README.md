## Shipping Volumetric Weight Calculator

Calculates volumetric (dimensional) weight for parcels and determines the chargeable weight (higher of actual vs volumetric) for four major carriers: FedEx, UPS, DHL, and USPS. Supports both metric (cm/kg) and imperial (in/lbs) units with a toggle. The carrier comparison table highlights which weight type applies (volumetric shown in yellow, actual in blue) for each carrier with their specific divisors.

**Tech:** Vanilla JS, Tailwind CSS CDN. No build step required.  
**Usage:** Enter package dimensions and actual weight, toggle unit system, and the table updates instantly.
